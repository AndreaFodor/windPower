In this folder we have the data that was used for this project, and jupyter notebooks containg the code we used to acquire this data.

We downloaded information on windfarms located in Quebec, which is made available by the Canadian government at: https://open.canada.ca/data/en/dataset/79fdad93-9025-49ad-ba16-c26d718cc070

In the notebook titled 'getWindFarmsFromHQ-checkpoint.ipynb' we scraped location information for the Wind Farms used by HydroQuebec from the HydroQeubec website: https://www.hydroquebec.com/electricity-purchases-quebec/electricity-contracts.html. 

In the notebook 'windfarm_weather_downloader-checkpoint.ipynb' we download weather data from the open-meteo website.
